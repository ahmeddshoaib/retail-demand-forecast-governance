# Data Provenance and Redistribution Controls

## M5 Forecasting - Accuracy

- Source: Kaggle M5 Forecasting - Accuracy competition.
- Unit used: daily item-store demand aggregated to 30 category-store series.
- Raw files: not committed to GitHub.
- Reproduction: users obtain the competition files from Kaggle and place them in `data/raw/`.
- Scholarly reference: Makridakis, Spiliotis and Assimakopoulos (2022).

## Public-repository boundary

This repository publishes original code, executed notebooks, aggregate evaluation
tables and dashboard screenshots. It does not redistribute M5 raw or processed
demand records. The submitted Power BI file is also excluded because it embeds
restricted data. Obtain the source competition files directly from Kaggle before
running the complete pipeline.
